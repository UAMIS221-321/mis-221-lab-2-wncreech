Extras:

Multiple new non-damaging moves were added to each character:

-Take Aim allows a player to reroll their Attacking Strength.

-Take Cover allows a player to reroll their Defending Power.

-Bandaging allows a player to heal a random small amount.

-Viewing another player's stats (Scoping) takes up a turn and has a chance to fail.

In addition, to speed up gameplay, the maelstrom now "intensifies" every four turns, increasing each player's max power by a random multiplier. Because players can reroll their attack and defense
powers, this adds an element of strategy - a player who rolls an inferior character can still win if he or she predicts the opponents moves correctly.
The max power can go over 100 through intensification, forcing the game to end at some point.

Special attention was also put towards making a slower, more enjoyable UI.
